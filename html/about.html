Why this site?

This mini-site is the vehicle for a DevOps project: what matters is not the site itself, but everything around it — the Git repository, the branches, the Pull Requests, the Docker image and the CI/CD pipeline that checks and builds every change.

The medina theme was chosen because a maze of alleys is a fairly good metaphor for a badly kept Git history — and this project aims for exactly the opposite: clean branches, readable commits, a well-marked path from code to deployment.

DS DevOps project — HTML / CSS / JS · Docker · GitHub Actions.
